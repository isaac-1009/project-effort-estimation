# 渠道管理Helpdesk — 工时估算分析

## 项目概述

- **项目名称**：渠道管理Helpdesk
- **项目类型**：企微H5应用（嵌入已有系统"美外之家-智汇工坊"）
- **使用对象**：前端-公司内部销售，后端-2名渠道运营管理员
- **主要目标**：为销售提供渠道管理类问题的自助查询+人工答疑服务，提升问题处理效率

## 技术方案

| 维度 | 方案 |
|------|------|
| 前端 | 企微H5（嵌入美外之家） |
| 后端 | Java/Node.js（复用美外之家技术栈） |
| 数据库 | MySQL/MongoDB |
| 对话实现 | 自定义聊天（WebSocket/SSE） |
| 离线推送 | 企微应用消息API |
| FAQ管理 | 内容固定配置 |
| 管理后台 | 嵌入美外之家后台（复用登录/权限） |

## 备注说明

1. **自定义聊天**：选择美外之家内自定义聊天方案，需完整开发WebSocket服务端和H5聊天界面，这是最大的工时占比。如改用企微客服消息API，可节省约10-12人天。
2. **FAQ内容**：当前为固定配置方案。如后续需要管理员在后台动态维护FAQ，需额外开发FAQ管理CRUD（约3人天）。
3. **复用已有系统**：管理后台嵌入美外之家，复用登录/权限/技术栈，无需额外认证开发。因在已有系统上开发，移除环境搭建工时。
4. **历史参考**：历史中无直接Helpdesk类项目，本次估算基于标准功能模式。随着类似项目积累，准确度将逐步提升。
