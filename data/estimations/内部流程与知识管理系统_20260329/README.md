# Current Estimation

当前正在进行的估算项目存放在此文件夹。

当估算确认无误后，使用 `scripts/archive_estimation.sh` 将其移动到历史估算文件夹中。

## 文件结构

```
current/
├── metadata.json          # 项目元数据
├── estimate.xlsx          # Excel估算文件
├── requirements.md        # 原始需求
├── pending_questions.md   # 待确认问题（如有）
└── analysis.md           # 项目分析总结
```
