# 企微图文推送投票功能设计文档

**项目**: 企微图文推送系统投票功能扩展
**日期**: 2026-05-27
**设计者**: Claude
**状态**: 草案调整

## 1. 项目概述

在现有企业微信图文推送功能的基础上，新增投票功能。用户阅读图文文章时，可以在文章详情页参与投票，管理员在创建推文时配置投票，在后台管理投票数据和导出结果。

### 1.1 核心目标
- **用户反馈收集**: 收集用户对内容或相关话题的意见和反馈
- **内容互动增强**: 增加图文内容的互动性和参与感

### 1.2 约束条件
- 基于现有企微图文推送系统扩展，复用现有技术栈
- 复用现有UI设计风格
- 无需环境搭建
- 权限控制复用推文的企微标签配置
- 投票配置集成到推文创建页面

## 3. 数据模型

### 3.1 投票主表 (votes)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 投票ID（主键） |
| article_id | String | 关联文章ID（外键） |
| title | String | 投票标题 |
| description | String | 投票描述（可选） |
| vote_type | Enum | 投票类型：single/multiple |
| max_choices | Integer | 最多可选数（多选时使用） |
| deadline | DateTime | 截止时间 |
| status | Enum | 状态：draft/active/closed |
| created_at | DateTime | 创建时间 |
| updated_at | DateTime | 更新时间 |

**说明**：权限配置复用推文（article）的标签配置，无需单独存储。

### 3.2 投票选项表 (vote_options)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 选项ID（主键） |
| vote_id | String | 投票ID（外键） |
| option_text | String | 选项文字 |
| option_image | String | 选项图片URL（可选） |
| sort_order | Integer | 排序序号 |
| created_at | DateTime | 创建时间 |

### 3.3 投票记录表 (vote_records)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 记录ID（主键） |
| vote_id | String | 投票ID（外键） |
| user_id | String | 用户ID |
| option_ids | JSON Array | 选择的选项ID列表 |
| voted_at | DateTime | 投票时间 |
| user_info | JSON | 用户信息快照（用于导出） |

### 3.4 索引设计

- votes表: (article_id), (status), (created_at)
- vote_options表: (vote_id)
- vote_records表: (vote_id, user_id) 唯一索引, (voted_at)

## 4. 功能设计

### 4.1 用户端功能：推文投票组件

一个完整的投票组件，包含以下功能：

#### 4.1.1 投票展示
- 投票标题和描述
- 选项列表（图文混排）
- 截止时间倒计时
- 实时票数显示

#### 4.1.2 投票交互
- **单选模式**: 点击选项后可修改，点击"提交投票"确认
- **多选模式**: 可选择多个选项（达到最大限制时提示），点击"提交投票"确认
- 投票前校验：
  - 用户是否在推文权限范围内（复用推文标签）
  - 投票是否已截止
  - 用户是否已投票
- 投票成功后立即显示结果

#### 4.1.3 结果展示
- 各选项票数和百分比
- 简单的柱状图展示
- 总参与人数

### 4.2 管理后台功能

#### 4.2.1 推文创建页扩展

在现有推文创建页面中，新增"添加投票"选项：

**投票基础信息**:
- 投票标题（必填）
- 投票描述（可选）
- 投票类型：单选/多选
- 截止时间设置

**选项管理**:
- 添加选项：文字 + 图片（可选）
- 拖拽排序
- 删除选项
- 最少2个选项，最多10个选项

**权限说明**:
- 复用推文的标签配置
- 在推文详情中明确说明："投票权限与推文查看权限一致"

#### 4.2.2 投票管理页面（新增）

独立的投票管理页面：

**投票列表**:
- 列表展示：投票标题、关联推文、状态、截止时间、参与人数、创建时间
- 状态筛选：草稿/进行中/已结束
- 快速操作：发布/关闭/删除/查看详情
- 点击投票可跳转到关联推文

**投票详情**:
- 投票配置信息
- 实时投票结果
- 参与用户列表

#### 4.2.3 投票数据页面（新增）

独立的投票数据分析页面：

**实时统计**:
- 各选项票数、百分比
- 参与情况：目标人数、已投票数、参与率
- 图表展示：柱状图、饼图

**投票明细**:
- 用户姓名、选择、投票时间
- 支持筛选和搜索

**数据导出**:
- 导出为Excel格式
- 包含完整投票明细

## 5. API设计

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/articles/:id/votes/create | 创建投票（关联文章） |
| PUT | /api/articles/:id/votes/:vote_id | 更新投票配置 |
| GET | /api/articles/:id/votes/:vote_id | 获取投票详情 |
| POST | /api/votes/:vote_id/submit | 提交投票 |
| GET | /api/votes/:vote_id/result | 获取投票结果 |
| GET | /api/votes/list | 投票列表 |
| DELETE | /api/votes/:id | 删除投票 |
| PUT | /api/votes/:id/status | 更新状态 |
| GET | /api/votes/:id/export | 导出数据 |

## 7. 技术实现要点

### 7.1 用户端（企微H5）
- 投票组件：独立的Vue组件，嵌入推文详情页底部
- 选项展示：图文混排，支持图片懒加载
- 交互反馈：投票动画、结果动画、加载状态
- 错误处理：权限不足、已投票、已截止等提示
- 企微JS-SDK：复用现有企微认证

### 7.2 推文创建页扩展
- 在现有推文创建表单中新增投票配置区域
- 投票配置为可选项，不创建投票则不影响原有功能
- 图片上传复用现有文件上传服务
- 选项拖拽排序使用现有UI组件库

### 7.3 管理后台新页面
- **投票管理页**：独立的列表页，支持筛选和快速操作
- **投票数据页**：独立的数据分析页，支持图表展示和导出
- 权限校验：通过推文标签验证用户权限

### 7.4 图片处理
- 复用现有文件上传服务
- 图片压缩：限制大小2MB以内
- 存储路径：/votes/options/{year}/{month}/
- 支持预览和删除

## 8. 扩展性考虑

1. **投票组件化**：投票组件独立封装，便于在其他场景复用
2. **数据模型**：投票表设计支持未来独立投票场景
3. **权限复用**：复用推文标签，简化权限管理
