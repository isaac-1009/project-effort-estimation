# Facility 需求追加 — 工时估算分析

## 项目概述

- **项目名称**：Facility 需求追加
- **项目类型**：现有系统新增功能（企微H5 + PC管理后台）
- **实施策略**：分阶段实施，各功能可独立开发上线
- **主要目标**：在现有美外之家系统上新增Facility Management相关功能模块

## 技术方案

| 维度 | 方案 |
|------|------|
| 前端 | 企微H5（嵌入美外之家） |
| 后端 | Java/Node.js（复用美外之家技术栈） |
| 数据库 | MySQL/MongoDB |
| 集成服务 | 企微API + Dify API + 智能门锁API + 腾讯地图/高德地图API |
| 管理后台 | 嵌入美外之家后台（复用登录/权限） |

## 功能模块说明

### 1. 员工survey（11人天）
- **用户端** (3人天): 员工填写survey表单，数据提交与展示
- **管理后台** (8人天): 表单设计器、字段配置、发布管理、数据统计、Excel导出

### 2. 失物招领（7人天）
- **用户端** (3人天): 查看失物list
- **管理后台** (4人天): 编辑失物list（增删改查）

### 3. 数据collection（6人天）
- **管理后台**: 预设数据收集及传输接口给DI Team

### 4. ISO 45001认证（2人天）
- **用户端**: 静态内容页面

### 5. EAG（2人天）
- **用户端**: 静态内容页面

### 6. 逃生指引+定位（0人天 - 需求未定）
- **用户端**: 腾讯/高德地图API集成+渲染页面+路线指引
- **状态**: 需求未定，待确认后评估

### 7. 厕位管理（0人天 - 需求未定）
- **管理后台**: 智能门锁API对接调试，门锁状态监控与管理
- **状态**: 需求未定，待确认后评估

### 8. AI chatbot（10人天）
- **用户端**: Dify API对接，聊天界面

## 待确认事项

1. **逃生指引+定位**: 需确认是否实施及具体需求范围
2. **智能门锁集成管理**: 需确认硬件选型及厂商对接情况

## 备注说明

1. 现有系统新增功能，环境搭建工时为0
2. Dify环境已由美敦力IT搭建，仅需API对接
3. 静态页面（ISO 45001、EAG）按2人天/个估算
4. Survey后台包含Excel导出功能
5. UI设计5人天涵盖已确定功能的界面设计
6. 各功能模块可独立开发上线，灵活调整优先级
