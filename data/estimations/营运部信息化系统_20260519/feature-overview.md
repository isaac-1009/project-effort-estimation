# 营运部信息化系统 — 功能一览

## 系统架构

| 端 | 平台 | 用户 | 说明 |
|----|------|------|------|
| 小程序端 | 微信小程序 | 店员、店长、品牌负责人、品牌财务 | 日常作业：提报、查阅、培训、进场 |
| PC管理后台 | Web (浏览器) | 营运、财务、市场、招商、管理员 | 后台管理：审核、配置、导出、维护 |

---

## 一、小程序端

### 1. 登录与注册

| 编号 | 功能 | 说明 |
|------|------|------|
| 1.1 | 扫码注册 | 扫描二维码进入注册页，填写个人信息，上传身份证正面（OCR自动识别姓名、身份证号），上传健康证照片，提交后台审核 |
| 1.2 | 审核状态查看 | 提交后展示审核中状态，审核通过后自动颁发电子员工证 |

### 2. 首页

| 编号 | 功能 | 说明 |
|------|------|------|
| 2.1 | 当前店铺展示 | 顶部展示当前所在店铺名称，点击可切换店铺 |
| 2.2 | 待办事项列表 | 集中展示：未提报销售提醒、未提交三关一闭、待确认业绩、营业执照到期预警、审批进度、活动通知、账单通知等 |

### 3. 工作台

| 编号 | 功能 | 说明 |
|------|------|------|
| 3.1 | 当前店铺展示 | 顶部展示当前店铺，点击可切换店铺 |
| 3.2 | 员工管理入口（第一位） | 培训视频、考试答题、员工入离职管理 |
| 3.3 | 销售管理入口 | 每日销售提报、月度销售提报 |
| 3.4 | 财务管理入口 | 账单下载 |
| 3.5 | 营运管理入口 | 三关一闭提报、资质档案、违纪/客诉查阅 |
| 3.6 | 市场相关入口 | 活动提交、积分抵现对账、合作信息 |
| 3.7 | 共享文件入口 | 制式单据下载 |

### 4. 销售管理

| 编号 | 功能 | 说明 |
|------|------|------|
| 4.1 | 每日销售提报 | 填写日期、店铺名称、店铺号、营业额等信息并提交，保留全部历史数据，支持Excel导出 |
| 4.2 | 月度业绩核对 | 查看当月销售汇总，店长线上确认业绩，支持Excel导出 |

### 5. 财务管理

| 编号 | 功能 | 说明 |
|------|------|------|
| 5.1 | 账单下载 | 按权限查看和下载店铺缴费账单（PDF格式），品牌财务可接收账单通知 |

### 6. 市场相关

| 编号 | 功能 | 说明 |
|------|------|------|
| 6.1 | 活动提交与确认 | 店铺提交活动内容和活动信息，营运审核确认，支持Excel导出 |
| 6.2 | 活动通知与总结 | 接收商场活动微信通知提醒，查看活动效果总结（会员销售占比等） |
| 6.3 | 积分抵现对账 | 店长发起每月积分抵现对账确认，填写固定表单，营运审核 |
| 6.4 | 商场合作信息 | 查看VIP折扣、员工折扣等合作信息，按权限展示 |

### 7. 营运管理

| 编号 | 功能 | 说明 |
|------|------|------|
| 7.1 | 三关一闭提报 | 拍照 + 文字备注提交每日三关一闭检查记录 |
| 7.2 | 资质档案管理 | 查看和上传资质信息：营业执照、经营许可证、保险等 |
| 7.3 | 品牌联系人变更 | 查看/变更店铺联系人信息 |
| 7.4 | 违纪查阅 | 店铺端查阅违纪汇总记录 |
| 7.5 | 客诉查阅 | 店铺端查阅客诉汇总记录 |

### 8. 员工管理

| 编号 | 功能 | 说明 |
|------|------|------|
| 8.1 | 培训视频 | 观看培训视频（入职培训、消防培训等分类） |
| 8.2 | 考试答题 | 观看视频后弹出考核答题页面（选择题），展示答题结果 |
| 8.3 | 员工入离职提报 | 入职：填写员工基本信息、健康证信息（含有效期），上传健康证照片，提交审核；离职：店铺端可自行删除离职员工信息 |

### 9. 共享文件

| 编号 | 功能 | 说明 |
|------|------|------|
| 9.1 | 制式单据下载 | 下载面试表、开票信息、通知函等参考文档 |

### 10. 我的

| 编号 | 功能 | 说明 |
|------|------|------|
| 10.1 | 电子员工证 | 直接展示电子员工证（含照片、姓名、店铺、有效期） |
| 10.2 | 实时动态时间 | 展示当前实时时间 |
| 10.3 | 进场状态 | 展示当前进场状态（已进场/未进场） |

---

## 二、PC管理后台

### 1. 登录

| 编号 | 功能 | 说明 |
|------|------|------|
| 1.1 | 微信扫码登录 | PC端通过微信扫码登录 |
| 1.2 | 账号密码登录 | 支持账号密码方式登录 |

### 2. 数据概览（首页）

| 编号 | 功能 | 说明 |
|------|------|------|
| 2.1 | 数据概览 | 今日进场人数统计、销售数据汇总、审批待办状态统计 |

### 3. 账号管理

| 编号 | 功能 | 说明 |
|------|------|------|
| 3.1 | 注册审核 | 审核员工注册申请（身份证信息、健康证），通过后颁发电子员工证 |
| 3.2 | 员工证管理 | 查看和管理所有电子员工证信息 |
| 3.3 | 多店铺权限配置 | 营运配置用户可查看的店铺列表（一人可能负责10家店，员工可能负责3家店） |

### 4. 销售管理

| 编号 | 功能 | 说明 |
|------|------|------|
| 4.1 | 销售数据查询 | 多维度查询每日销售提报数据，支持Excel导出 |
| 4.2 | 月度销售数据 | 查看月度销售汇总数据，支持Excel导出 |

### 5. 财务管理

| 编号 | 功能 | 说明 |
|------|------|------|
| 5.1 | 账单管理 | 财务导出账单、上传账单PDF，通过微信通知+邮件发送给品牌财务 |

### 6. 市场管理

| 编号 | 功能 | 说明 |
|------|------|------|
| 6.1 | 活动审核 | 审核店铺提交的活动申请，发布活动效果总结 |
| 6.2 | 积分抵现审核 | 审核店铺提交的积分抵现对账申请 |
| 6.3 | 合作信息维护 | 维护商场合作信息：VIP折扣、员工折扣等，支持按权限展示 |

### 7. 营运管理

| 编号 | 功能 | 说明 |
|------|------|------|
| 7.1 | 三关一闭统计 | 查看各店铺三关一闭提交统计 |
| 7.2 | 店铺信息管理 | 店铺基本数据录入/编辑，状态管理，资质档案审核（营业执照、经营许可证、保险），品牌联系人管理（合并原店铺管理和店铺信息管理） |
| 7.3 | 品牌信息维护 | 品牌CRUD维护，变更品牌负责人和品牌财务 |
| 7.4 | 违纪/客诉上传 | 营运上传违纪信息、客诉信息，店铺端可查阅 |

### 8. 员工管理

| 编号 | 功能 | 说明 |
|------|------|------|
| 8.1 | 培训视频管理 | 分类管理培训视频（入职培训、消防培训等），支持上传 |
| 8.2 | 试卷配置 | 配置选择题题库及答案，关联培训视频 |
| 8.3 | 答题记录查询 | 查询员工答题历史和成绩 |

### 9. 系统设置

| 编号 | 功能 | 说明 |
|------|------|------|
| 9.1 | 系统用户角色维护 | 8角色定义和权限管理（营运、财务、市场、招商、品牌负责人、品牌财务、店长、店员） |
| 9.2 | 小程序用户角色维护 | 用户管理、角色绑定、多店铺权限配置 |

---

## 三、用户角色权限

| 角色 | 端 | 主要权限 |
|------|-----|---------|
| 店员 | 小程序 | 销售提报、三关一闭、查阅信息、培训考试 |
| 店长 | 小程序 | 店员权限 + 业绩确认、积分对账发起、员工入离职管理 |
| 品牌负责人 | 小程序 | 查看业绩、确认对账 |
| 品牌财务 | 小程序 | 接收账单通知、账单下载 |
| 营运 | PC后台 | 审核活动、上传违纪/客诉、配置权限、店铺管理、品牌维护 |
| 财务 | PC后台 | 导出账单、发送通知 |
| 市场 | PC后台 | 活动审核、总结发布 |
| 招商 | PC后台 | 合作信息维护 |
| 管理员 | PC后台 | 系统设置、用户角色管理 |
