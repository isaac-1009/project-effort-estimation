# RGI 荣誉勋章 — 需求摘要

> 来源：`rgi 荣誉勋章 0910.pdf`（Medtronic IT，Dec. 2025，9 页 PPT）
> 定位：RGI 企业微信模块下的「荣誉勋章」子应用 —— 销售专业能力展示 + 员工互动社区

## 项目背景

1. 提供一个可供销售向客户展示自身专业能力的平台（对外展示）
2. 兼顾 RGI 销售员工间的互动、互助、社交（对内互动）

PPT 第 2 页为 HCD 开发流程（Empathize → Define → Ideate → Prototype(Figma) → Test → Development & release），
说明客户按 HCD 流程推进、原型基于 Figma，开发在原型评审通过后启动。

## 用户分类（P4/P5）

| 角色 | 推测全称 | 分类 | 权限 |
|------|---------|------|------|
| 销售 | — | 主用户 | 对外展示、对内互动 |
| DSM | District Sales Manager 地区销售经理 | 辅助 | 评价、查询 |
| TCS | 培训/临床专员 | 辅助 | 输入、维护 |

## 细分需求（P6/P7，按 对外展示端 / 对内互动端 × TCS / DSM / TSR）

**TCS**
- 对外展示端：
  - 数据录入：后台维护培训数据，定期更新销售专业能力
  - 行为解锁：后台维护行为评估，解锁销售实战 TAG 1/3
- 对内互动端：
  - 留言评价：对培训和行为进行留言点评

**DSM**
- 对外展示端：
  - 数量解锁：后台维护跟台数量，解锁销售实战 TAG 1/3
  - 口碑解锁：后台维护客户评价，解锁销售实战 TAG 1/3
- 对内互动端：
  - 能力搜索：按产品线能力查找同事寻求帮助
  - 背景搜索：按个人经历（友商）TAG 搜索

**TSR（销售代表，主用户）**
- 对外展示端：
  - 能力展示：选中个人能力卡片，展示被认证的专业技能
  - 维度展示：六边形雷达图展示多产品专业培训等级（可选）
- 对内互动端：
  - TAG 系统：实战跟台、项目先锋、友商经历…
  - 社区互动：感谢同事帮助、赞美精湛技艺…

## 原型要点（P8/P9 手机截图）

**对外展示 — One Page「可扩展式名片」**
- 「我的能力」页：头像/姓名/职位（地区经理）/地区（上海）+ Medtronic logo + 分享按钮
- TAG 徽章：如「PFA先锋」「Surgical Champion」
- 六大产品线卡片（NV / CRDN / CAS / CRM / Surgical / Aortic），各配主题色，可展开
- 每条产品线下展示已认证的细分能力清单（如 NV：脑血管解剖、脑血管疾病、神经介入疗法、
  神经介入手术规划、神经介入手术跟台），带认证日期

**对内互动 — RGI 荣誉勋章主页**
- 搜索项目/能力
- 个人统计：勋章数（示例 6）/ 完成培训（32）/ 被点赞（40）
- 我的能力墙（可编辑、可跳转「去展示」）
- 产品线图标矩阵：被点亮 = 至少完成该产品线其中一级培训
- 解锁最新 tag：三步进度（直线经理 ✓ → TCS ✓ → 客户）
- 「我的能力」页：能力分 Lv.1 / Lv.2 等级；未获得的细分能力灰显但仍可见

**展示规则（P9 文字）**：展示已获得的各项 TAG、被点赞数量、完成培训课程数量、
被点亮的产品线；进入能力墙可查看细分能力（包括尚未获得的）。
